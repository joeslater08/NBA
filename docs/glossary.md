# Glossary

- **Fixture:** scheduled game with stable identity, opponents and UTC start.
- **Market:** a structured statistic, direction, threshold and settlement rule set.
- **Push:** actual equals an over/under line; stake returned under supported rules.
- **Void:** selection cancelled under explicit rules; stake returned.
- **Paper unit:** virtual measurement, nominally £1; no money moves.
- **Decimal odds:** total return multiplier, including the returned stake.
- **ROI:** virtual net return divided by recorded settled stake.
- **Calibration:** whether events assigned a probability occur at that frequency over enough independent observations.
- **Provenance:** where data came from, when it was retrieved and whether it was checked.
- **Immutable:** cannot be edited in place after recording.
- **Leakage:** using information that was not available when a forecast would have been made.
- **Monte Carlo:** repeated sampled computation under explicit assumptions, not proof those assumptions are correct.
